# 💊 Analyse des Ventes de Médicaments avec Excel

## 📌 Description

Ce projet a été réalisé avec Microsoft Excel afin d'analyser les ventes de médicaments à partir de différentes informations commerciales et logistiques.

L'objectif est d'étudier les performances des produits, le chiffre d'affaires généré, les marges réalisées et l'état des stocks afin d'aider à la prise de décision.

## 📁 Contenu du projet

- Base de données des médicaments
- Analyse des ventes
- Calcul du chiffre d'affaires (CA)
- Analyse des marges brutes
- Suivi des stocks
- Tableau de synthèse

## 📊 Données analysées

Les données comprennent notamment :

- Code produit
- Nom du médicament
- Catégorie
- Fournisseur
- Quantité vendue
- Prix unitaire
- Chiffre d'affaires
- Marge brute
- Statut du stock
- Tendances de vente

## 📈 Analyses réalisées

- Calcul automatique du chiffre d'affaires
- Évaluation de la rentabilité des produits
- Analyse des performances par catégorie
- Identification des produits les plus vendus
- Contrôle des niveaux de stock
- Création de tableaux et indicateurs de suivi

## 🛠️ Outils utilisés

- Microsoft Excel
- Formules avancées
- Mise en forme conditionnelle
- Tableaux d'analyse
- Visualisation de données
